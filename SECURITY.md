# Security Notes

SecuRift is an academic defensive network detection-engineering project.

## Scope
- PCAP inspection and defensive detection validation
- Snort rule authoring and execution where Snort is installed
- Alert triage, false-positive analysis, and reporting

## Not supported
- Attack generation
- Exploit execution
- Malware deployment
- Credential theft or brute-force tooling

## Reporting a vulnerability
Please do not include secrets, credentials, private PCAPs, or other sensitive artifacts in a public issue. For a real deployment, use a private security-reporting channel and rotate any exposed credentials immediately.
