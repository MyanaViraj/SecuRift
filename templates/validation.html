🎓 Detection Engineering Mathematical Formulas (College Viva Reference)

Statistical Rigor
1. Detection Rate (True Positive Rate / Recall):
Detection Rate = [ TP / (TP + FN) ] × 100
Measures proportion of real attack packets/cases correctly identified. Returns N/A if attacks = 0.
2. False Positive Rate (Fall-out):
False Positive Rate = [ FP / (FP + TN) ] × 100
Measures proportion of benign traffic wrongly flagged as attacks. Returns N/A if benign = 0.
3. Precision (Positive Predictive Value):
Precision = [ TP / (TP + FP) ] × 100
Probability that an alert generated by Snort indicates a true threat. Returns N/A if alerts = 0.
4. Overall Accuracy:
Accuracy = [ (TP + TN) / (TP + TN + FP + FN) ] × 100
Overall correctness of the detection system across all test vectors.
